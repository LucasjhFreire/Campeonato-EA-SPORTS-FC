# 🎮 Campeonato EA Sports FC - Trabalho da Faculdade

Projeto desenvolvido para a matéria da faculdade com o objetivo de criar um sistema para gerenciar um campeonato de EA Sports FC, controlando a tabela de classificação, jogos e estatísticas.

---

## 🚀 O que o projeto faz?

- 🏆 Tabela de classificação automatizada (Pontos, Vitórias, Derrotas, Saldo de Gols).
- ⚽ Cadastro e exibição dos resultados das partidas.
- 📊 Cálculo das estatísticas do torneio.

---

## 🛠️ Tecnologias Usadas

- **HTML5:** Estrutura e tabelas.
- **CSS3:** Estilização e bordas.
- **Python:** Lógica e cálculos do campeonato.
